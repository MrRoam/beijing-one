核查日期：2026-09-13。对象为北航于 1958 年研制的双发轻型旅客机“北京一号”。

## 当前结论

**在本次公开检索范围内，未发现可直接下载、并有明确复用条件的北京一号飞机三维模型。现有 Blender 5.0.1 已实际验证可用，可以按自主复原方案准备。**

这不等于证明世界上或校内没有模型。校庆网站曾出现相关视觉展示，校内还可能保留未公开的制作文件。本次没有联系作者、校方或博物馆，也没有获得这些文件或授权。后续若取得可用模型，应重新评估复用，替换对应制作环节。

## 制作方案

以 Blender 为主，使用 Python 脚本保存关键尺寸与生成过程；曲面外观通过多个视角的渲染与参考图核对。只有在装配接口确实需要时才增加参数化 CAD 工具。当前不依赖 computer use 或第三方 Blender MCP 插件。

维护一个基础外形模型，派生网站展示版与打印版。源文件以米为单位组织；网页 GLB 保持一致单位；打印 STL 显式换算为毫米，避免尺寸放大或缩小 1000 倍。

### 阶段 1：资料和比例基准

整理实机前、侧、后及机翼、发动机短舱、尾翼、起落架的参考资料。优先以馆藏实机外观作为初稿依据，标注每条尺寸与细节的来源、可信程度以及照片视角。建立“已证实 / 推测 / 缺资料”清单。

交付：参考资料索引、尺寸表、外形轮廓草图。对来源不一致的数值保留差异，不随意拼成一套假精确尺寸。

完成条件：足以确定机身长宽比例、机翼位置和轮廓、双发短舱及尾翼布局。难以确认的细节先保留可修改结构。

### 阶段 2：比例草模

建立机身、主翼、左右短舱、平尾、垂尾及螺旋桨的基础形体。通过正交前视、侧视、顶视和透视角度检查轮廓，再进入细节。

交付：可编辑 `.blend` 和多视图预览。

完成条件：主要外形与参考一致，左右对称，部件位置合理，尺寸可回溯。此时不投入内部结构和不可见零件。

### 阶段 3：完整外观

细化机头、驾驶舱玻璃、客舱窗、舱门、翼身连接、发动机短舱与桨叶；根据可靠参考制作涂装。将螺旋桨分为可独立旋转的对象，设置正确的轴心。保留干净的部件名称与层级。

交付：完整外观源模型、材质及预览图。

完成条件：常用展示角度没有明显破面、穿插或错误阴影；参考未覆盖的部分明确标注为近似复原。

### 阶段 4：网页展示版

制作轻量 GLB 和独立的本地网页预览，提供旋转、缩放、复位和螺旋桨启停。历史介绍只采用已有来源支持的事实。

初始目标：三角面控制在约 10 万以内、GLB 约 10 MB 以内；这是性能预算，必要时根据效果与实际设备调整。保留源模型，优化发生在导出副本上。

交付：`.glb`、网页预览及运行说明。

完成条件：浏览器实际加载成功、材质和方向正确、旋转轴心正确、交互正常。此阶段不包含向公网部署。

### 阶段 5：打印版

暂定 1:72 桌面比例，最终外形尺寸根据阶段 1 的尺寸表计算。按打印机成型空间决定拆件，优先考虑机身、左右机翼、尾翼和底座；对桨叶、起落架等细节选择加厚、独立打印或展示姿态简化。

装配间隙、最小壁厚、支撑方向和材料取决于实际打印设备，不预先把某个数值当作通用答案。新增接口先做小型配合试片。

交付：毫米单位 STL、装配示意、尺寸和打印建议；在切片器与机型确定后再提供相应 3MF 项目。

完成条件：各打印件闭合、无明显自交与悬空碎片；切片预览尺寸、层结构和支撑合理。实际装配合格需等试打印反馈，软件检查不能代替这一项。
