## 模型与导出

Blender 5.0.1 后台脚本执行完成，源工程重新打开并整理初始视角。外观四视图、打印装配图、爆炸图和比例图已渲染并检查。GLB 为版本 2，自包含，1,147,120 字节，42,218 个三角面；两个螺旋桨节点可独立控制。

打印源几何检查包括非流形边、连通体、正体积及非相邻三角面相交候选检查。11 种零件全部通过，每件单一连通体。导出文件又由独立 Python 标准库脚本回读，验证 STL 长度、有限坐标、共享边闭合、面方向、退化面、尺寸及平台位置。全部通过。

回读曾发现后机身凹多边形的默认导出三角化生成四面共边；已在生成脚本中显式三角化，重新生成并验证最终文件。这避免了只检查导出前网格而遗漏实际文件问题。

装配按实体布尔求交检查飞机、连接销和底座，共检查 18 对包围盒相交候选，超过 0.01 mm³ 的干涉为 0。设计中的底座肩部干涉已通过贴合机腹曲面的形状调整消除。该检查不测量摩擦、材料变形或加工误差。

每个 STL 另取 12%、50%、88% 高度截面，均未检出开放端点。仅采样几何截面，不等同于逐层切片。三个通用 3MF 的 ZIP、XML、三角索引、毫米单位和装配引用检查通过。参考板上各实例的包围盒无重叠，未计入真实支撑、brim 和设备禁入区。

机器可读证据：`asset-validation.json`、`../print/manifest.json`、`../print/assembly-check.json`。

## 网页

在本地服务 `http://127.0.0.1:8765/web/` 实际加载了 GLB。检查总览、侧视、俯视、正视、螺旋桨启停、起落架显示开关、缩放和复位按钮；按下状态、文字与模型显示正常。鼠标拖动可改变观察方向。来源说明可展开，导航可到达下载区域。最终浏览器错误日志为空。

检查桌面及 390 × 844 的手机视口，页面无水平溢出、控件在页面内。测试中发现初次渲染写入的固定画布宽度影响后续缩放，已改为 CSS 控制画布尺寸；复查画布宽度与容器一致。手机检查为浏览器视口模拟，不是实体手机 GPU 测试。

页面引用的本地样式、脚本、预览图片及四个下载目标通过 HTTP 实际读取，共 9 次检查均返回 200。下载属性存在；未自动触发系统“另存为”流程。结果记录在 `web-file-check.json`。Three.js 依赖随包提供，不使用 CDN。
